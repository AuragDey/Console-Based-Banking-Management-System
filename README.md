# 🏦 Console-Based Banking Management System (Java)

> A simple yet well-structured **banking management system built using Core Java**, designed to demonstrate strong fundamentals in **object-oriented programming, clean coding practices, and basic security concepts**.

---

## ✨ Features
- 🏦 Create **Savings** and **Current** bank accounts  
- 🔐 **PIN-based authentication** for secure deposits and withdrawals  
- 💰 Deposit and withdraw money with balance validation  
- 📜 Transaction history tracking  
- 💾 Persistent storage using file handling (data retained between runs)  
- 🧩 Clean separation of logic using OOP principles  

---

## 🛠️ Tech Stack
- **Language:** Java  
- **Concepts Used:**  
  - Object-Oriented Programming (Abstraction, Inheritance, Polymorphism)  
  - Collections Framework  
  - File I/O and Serialization  
  - Exception Handling  

---

## 📁 Project Structure
```text
banking-management-system/
├── Main.java                      # Entry point & menu handling
├── Bank.java                      # Core business logic
├── Account.java                   # Abstract base class
├── SavingsAccount.java            # Savings account implementation
├── CurrentAccount.java            # Current account implementation
├── Transaction.java               # Transaction model
├── DataStore.java                 # File persistence logic
└── AccountNotFoundException.java  # Custom exception
```

---

## ▶️ How to Run
1. Clone the repository  
2. Open the project in any Java IDE (IntelliJ / Eclipse / VS Code)  
3. Compile and run `Main.java`  
4. Follow the on-screen menu  

_No external libraries required 🚀_
